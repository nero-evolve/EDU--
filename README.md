# 位元探險隊｜數位資料解碼任務

給八年級學生的自學闖關課程，共六章：數字線索、0 和 1、二進位拼圖、文字編碼、像素圖片與聲音取樣。數字和位元由少到多逐步練習，每章有短說明、練習和章末檢核。學生可看提示並重試，練習不扣分。

學生使用五位數班級座號登入，進度同步至 Supabase；教師可在後台查看任務進度、六關檢核分數並留下評語。

## 功能

- 學生輸入五位數班級座號即可登入，例如 `90230` 代表 902 班 30 號。
- 教師建立三位數班級碼；座號前 3 碼需符合班級碼，後 2 碼為座號。
- 每次學生作答、提示、進度和系統分數都同步到雲端；教師可檢視逐題答案、調整核定分數並留下評語；登入頁支援密碼重設。
- 課程步驟、學生用語、例題與任務圖解已重新編排；互動包括數字卡解碼、拖放位元拼圖、像素塗畫和聲音取樣滑桿。
- 學生可依建議順序學習，也能從任務地圖或課程選單直接選章練習；跳章不會自動算成完成。
- 檢核分數以六關章末題平均計算；練習答錯、看提示及重試都不扣分。

## 部署與資料庫

第一次設定請依 [SETUP.md](./SETUP.md)。教師核定分數功能請先執行 `teacher-score-overrides.sql`；已有班級碼登入的專案不要重跑整份 `supabase.sql`。若要清除尚未正式使用的測試班級和紀錄，可先檢查並執行 `reset-trial-data.sql`；這會保留教師登入帳號。

## 程式檔案

`app.js` 管理學生和教師介面；`engine.js` 管理任務、檢核分數與進度；`content.js` 放分階段課程文字和題目；`visuals.js` 用 SVG 繪製新圖解；`cloud.js` 串接 Supabase；`supabase.sql` 設定班級、進度及資料權限。
